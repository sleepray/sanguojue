## 一、ID 规则与验证

bundle 名里的数字（`general_big_static_2588`）**不是武将 ID**，只是包序号；真实 ID 在包内路径：

```
assets/res/localh5picture/general/big/static/100.png   ← 100
assets/res/localh5picture/general/seat/static/100.png  ← 100
```

规则：**武将 ID = static_id / 100**。验证方式是与项目现有图逐像素比对：

| 类型 | 比对 | 结果 |
| --- | --- | --- |
| big | 项目 `assets/big/001..057.png` | **54/54 像素 md5 完全一致** |
| seat | 项目 `assets/seat/001..057.png` | **56/56 像素 md5 完全一致** |

不一致 0 张，规则成立。
