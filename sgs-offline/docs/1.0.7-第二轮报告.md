1. **横屏锁定**：`AndroidManifest.xml:22` 为 `sensorLandscape`，设备旋转 0/1 均不重排；若需竖屏 APK，要改 manifest（并重跑 5 视口适配），需确认。
2. **qa_e2e.js 旧选择器**：仍直接点 `#btn-settings/#btn-trust/#btn-save/#btn-surrender/#btn-quit`，这些已收进隐藏菜单；本轮未改 qa_e2e（新增 `ui_probe.js` 覆盖同类路径），需后续改为「先点更多」或 DOM click。
3. **结算页按钮高度 35px**：低于 44 基线，但不在任务 1 的顶栏/设置范围内；A 的检查器未把结算按钮列为交互元素，是否补 44 需确认。
4. **safe-area 精度**：honor cutout overlay 下截图确认无遮挡；CDP 读不到精确 inset，`innerWidth` 未变化，建议真机复核。
5. **chooseTargets 验证方式**：真实牌局随机触发不稳定，pick-bar/返回键用「真实开局 + 注入请求」验证同一 UI 路径；可后续用具体锦囊补真实触发用例。
