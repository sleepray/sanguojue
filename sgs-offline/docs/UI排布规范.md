# UI 排布规范（1.0.7）

> 适用：`sgs-offline` 网页与 Android WebView 壳。证据来自 1.0.7 当前代码与 B2 实测；后续新增界面/弹窗按本规范执行。

## 1. 按钮位置与顺序

1. **确认在右、取消在左**。所有弹窗底部统一为 `取消/放弃` 在左、`确认/打出` 在右：
   - 选牌：`js/ui.js:3270-3271`（cancel → confirm）
   - 选目标：`js/ui.js:3285-3286`
   - 隐藏选牌：`js/ui.js:3393-3394`
   - 确认框：`js/ui.js:3977-3978`（`data-c="0"` 取消、`data-c="1"` 确认）
   - 选目标顶部 `#pick-bar`：取消左、确认右（`js/ui.js:2252-2257` 对应实现）
2. **同一界面同等权重的常驻按钮不超过 3 个**。当前对局顶栏有 6 个（设置/战报/保存/托管/投降/返回，`index.html:160-166`），超过规则；应分组或收进“更多”，但本轮不做布局改动，见 B4 方案。
3. **危险操作必须二次确认**：
   - 投降、退出对局已有确认（`js/main.js` `onSurrender/onQuit`；实测返回键弹“退出本局将判负”）。
   - `结束出牌`、`不响应`、`弃牌` 当前为单击立即执行（`js/ui.js:2520`、`2566`、`2585`），属于高风险高频操作，建议至少给 `结束出牌`/`弃牌` 二次确认或短 undo；本轮只记录方案。
4. **危险按钮不与高频按钮相邻**：顶栏 `投降`/`返回` 紧邻 `保存`/`托管`（`index.html:163-166`），在 412px 宽下按钮仅 28×24，误触风险高；方案是危险项收进二级菜单。
5. **结果页**：`再来一局` 为主按钮在左、`返回主菜单` 为次按钮在右（`index.html:397-398`），与“主操作在右”不严格一致；本轮不改，列入方案。

## 2. 触控与字号

1. 可点击区域最小 **44×44 CSS px**；文字不小于 **12px**（A 的 `layout_check.js` 规则）。
2. 当前实测（412×915）：顶栏 6 个按钮均为 **28×24**，设置关闭按钮 **19×25**，设置滑杆高 5px，`暂停游戏` 80×31（`index.html:161-166/291/296/300/326`）。这些低于 44×44，列为 P1 触控风险，需 A 统一处理；B 不直接改 `style.css`。静音开关原 40×22，已通过 `.switch-mute` 补到 44×44。
3. 开关类控件使用整行 label 点击（`.setting-row .switch`），不要只让 13×13 的 input 可点；静音开关已加 `.switch-mute` 把热区补到 44×44（`css/ui-107.css`），视觉轨道仍 40×22。

## 3. 弹窗与层级

1. 弹窗统一用 `.modal-mask > .modal`，标题/原因/内容/按钮四段结构；同类弹窗（选牌/选目标/是否发动技能）沿用同一套按钮顺序与文案。
2. 弹窗打开时底层不可点；暂停遮罩 `z-index:500` 覆盖全部（`css/style.css:3441-3446`），实测底层点击命中 `resume-card`。
3. 返回键只关闭“可关闭的最上层”（设置/战报/详情）；强制选择弹窗、退出确认、暂停遮罩不关闭，避免误放弃/误退出（`js/main.js:598-632`）。
4. 弹窗打开时切后台/暂停：弹窗与已选必须保持；实测选牌 `1/1`、选目标 `picked=1`、响应 `45s` 均保持，无重复弹窗。

## 4. 暂停与后台

1. 唯一入口 `SGS_APP_PAUSE(paused, opts)`（`js/main.js:634-656`）：
   - 后台：`SGS_APP_PAUSE(true)`，冻结引擎、读秒、音频；回前台不自动解除。
   - 手动暂停：`SGS_APP_PAUSE(true,{keepAudio:true})`，冻结引擎与读秒，保留 BGM。
2. 暂停面板打开时底层不可点，倒计时冻结；关闭后从剩余时间继续，不重置、不跳秒（实测 90→90，恢复后 89）。
3. 静音与暂停分离：静音只关闭音频总开关（`SGS_AUDIO.enabled=false`），不改变暂停态；静音后切后台再回不得自动有声；未静音时解除暂停正常恢复（`js/main.js:54-67`、`675-681`）。

## 5. 返回键（Android）

1. `MainActivity.handleBack()` 调 `SGS_BACK()`，只有返回非 `"true"` 才 `finish()`（`MainActivity.kt:148-158`）。
2. 主菜单返回 `false`；对局返回 `true` 并弹退出确认；设置/战报/选将/结算/普通弹窗/暂停遮罩返回 `true` 且不误退出。
3. 设置面板必须用 `.settings-panel.is-open` 判断（已修，`js/main.js:609`）；此前误用 `.is-on` 会把返回落到退出对局。

## 6. 安全区与系统字体

1. `index.html:5` 使用 `viewport-fit=cover`；`css/style.css:2313-2318` 等使用 `env(safe-area-inset-*)`，顶部/底部栏避开刘海与手势条。
2. `MainActivity.kt:90` 已固定 `textZoom = 100`，系统字体放大不会改变 WebView 文本缩放；无需人工决策。
3. 横竖屏切换需保持：顶栏/按钮不超出视口、弹窗居中、设置面板在右；实测 412×915、915×412、800×1280、1280×800 的 `#btn-quit` 均在视口内，弹窗矩形未越界。

## 7. 功能入口原则

1. 对局中高频/紧急（暂停、静音）应 1 次点击可达；低频偏好（音量、动画、节奏）放设置。
2. 不可撤销（退出、投降、重开）不放常驻首位，必须二次确认。
3. 对局界面新增常驻图标总数不超过 3 个，且 323×792 下不遮挡座位、手牌、按钮栏；未通过 5 视口 `layout_check.js` 前不得上线。
