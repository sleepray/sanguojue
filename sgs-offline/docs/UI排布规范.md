# UI 排布规范（1.0.7）

> 适用：`sgs-offline` 网页与 Android WebView 壳。证据来自 1.0.7 当前代码与 B2 实测；后续新增界面/弹窗按本规范执行。

## 1. 对局顶栏与按钮顺序

1. **顶栏只保留 3 个可见按钮：暂停 | 战报 | 更多**（`index.html:161-164`）。
   - 暂停：`#btn-pause`，1 次点击直达，调用 `SGS_APP_PAUSE(true,{keepAudio:true})`（`js/main.js:521-526`、`534`）。
   - 战报：`#btn-log`，1 次点击。
   - 更多：`#btn-more`，打开 `#more-menu`（`index.html:164-172`）。
2. **「更多」菜单分组**：设置 / 托管 / 保存 在上，分隔线 `.more-sep` 之下放危险项 投降 / 退出（`index.html:165-172`）；危险项与常用项不得相邻。
   - 菜单默认 `display:none`，`#more-menu.is-open` 才显示（`css/style.css` 末尾 B2 段）。
   - 点菜单外部、点任一菜单项、按返回键、切屏都会关闭菜单（`js/ui.js:660-663`、`js/ui.js:694-699`、`js/ui.js:775`、`js/main.js:613-618`）。
3. **确认在右、取消在左**。所有弹窗底部统一为 `取消/放弃` 在左、`确认/打出` 在右：
   - 选牌：`js/ui.js:3324-3325`
   - 选目标：`js/ui.js:3339-3340`
   - 隐藏选牌：`js/ui.js:3399-3400`
   - 确认框：`js/ui.js:4031-4032`（`data-c="0"` 取消、`data-c="1"` 确认）
   - 选目标顶部 `#pick-bar`：暂停 / 取消 / 确认从左到右（`js/ui.js:2981-2983`）。
4. **危险操作必须二次确认**：投降、退出对局保留确认框（`js/main.js:535-557`）；`结束出牌`、`不响应`、`弃牌` 仍是单击立即执行（`js/ui.js:2540`、`2586`、`2605`），列为待评估项，不在本轮改动。
5. **结果页主操作在右**：`返回主菜单`（次）在左、`再来一局`（主）在右（`index.html:400-401`）。

## 2. 触控与字号

1. 可点击区域最小 **44×44 CSS px**；文字不小于 **12px**（A 的 `layout_check.js` 规则）。
2. 本轮已达标（323×792、412×915 实测）：
   - 顶栏 3 按钮：**52×44**，字号 **12px**（`#btn-pause/#btn-log/#btn-more`）。
   - 更多菜单项：**162×44**，字号 **12px**；菜单整体在视口内。
   - 设置关闭按钮：**44×44**；两个音量滑杆输入区：**44px 高**（视觉轨道仍 5px）；动画/静音开关：**44×44**（视觉轨道 40×22）。
   - 选目标 pick-bar 暂停按钮：**44×44**。
3. 开关类控件使用整行 label 点击（`.setting-row .switch`），不要只让 13×13 的 input 可点；`.switch-mute` 与设置行通用规则都把热区补到 44×44（`css/ui-107.css`）。
4. 其余界面（主菜单 38 高、动作栏 21 高、结算 35 高等）仍低于 44，由 A 的 `layout_check.js` 统一登记，不在本轮 B 的顶栏/设置范围内。
5. 本轮用 A 的 `layout_check.js` 定向复测 `settings/pause/play5` 五视口（323/412/619/800/1280）：**P0=0、P1=0**；全量 15 场景由 A 执行。

## 3. 弹窗与层级

1. 弹窗统一用 `.modal-mask > .modal`，标题/原因/内容/按钮四段结构；同类弹窗（选牌/选目标/是否发动技能）沿用同一套按钮顺序与文案。
2. 弹窗打开时底层不可点；暂停遮罩 `z-index:500` 覆盖全部（`css/style.css:3441-3446`），实测底层点击命中 `resume-card`。
3. 「更多」菜单 `z-index:210`，高于顶栏/面板、低于暂停遮罩（500）与弹窗；菜单打开时点外部关闭，不阻塞牌局。
4. 返回键只关闭“可关闭的最上层”（更多菜单/设置/战报/详情）；强制选择弹窗、退出确认、暂停遮罩不关闭，避免误放弃/误退出（`js/main.js:606-645`）。
5. 弹窗打开时切后台/暂停：弹窗与已选必须保持；实测选牌 `1/1`、选目标 `picked=1`、响应 `45s` 均保持，无重复弹窗。

## 4. 暂停与后台

1. 唯一入口 `SGS_APP_PAUSE(paused, opts)`（`js/main.js:649-671`）：
   - 后台：`SGS_APP_PAUSE(true)`，冻结引擎、读秒、音频；回前台不自动解除。
   - 手动暂停：`SGS_APP_PAUSE(true,{keepAudio:true})`，冻结引擎与读秒，保留 BGM。
2. 手动暂停入口：顶栏 `#btn-pause`（`js/main.js:521-526`）；选目标时 pick-bar 内 `[data-pick="pause"]` 走同一 `triggerPause()`（`js/ui.js:3021-3026`），先收起菜单/设置/战报再暂停。
3. 暂停面板打开时底层不可点，倒计时冻结；关闭后从剩余时间继续，不重置、不跳秒（实测 90→90，恢复后 89）。
4. 静音与暂停分离：静音只关闭音频总开关（`SGS_AUDIO.enabled=false`），不改变暂停态；静音后切后台再回不得自动有声；未静音时解除暂停正常恢复（`js/main.js:54-67`、`675-681`）。

## 5. 返回键（Android）

1. `MainActivity.handleBack()` 调 `SGS_BACK()`，只有返回非 `"true"` 才 `finish()`（`MainActivity.kt:148-158`）。
2. 优先级：「更多」菜单 → 暂停遮罩 → 武将详情 → 设置 → 战报 → 强制弹窗 → 结算 → 选将 → 对局退出确认（`js/main.js:606-645`）。
3. 主菜单返回 `false`；对局返回 `true` 并弹退出确认；更多菜单/设置/战报/选将/结算/普通弹窗/暂停遮罩返回 `true`，其中可关闭面板关闭、强制弹窗与暂停遮罩保持。
4. 设置面板必须用 `.settings-panel.is-open` 判断（已修，`js/main.js:624`）；此前误用 `.is-on` 会把返回落到退出对局。

## 6. 安全区与系统字体

1. `index.html:5` 使用 `viewport-fit=cover`；`css/style.css:2313-2318` 等使用 `env(safe-area-inset-*)`，顶部/底部栏避开刘海与手势条；pick-bar 顶部也加了 `env(safe-area-inset-top)`（`css/style.css` B2 段）。
2. `MainActivity.kt:90` 已固定 `textZoom = 100`，系统字体放大不会改变 WebView 文本缩放；无需人工决策。
3. 横竖屏切换需保持：顶栏/按钮不超出视口、弹窗居中、设置面板在右；实测 323×792、412×915、619×792、915×412、1280×800 的顶栏按钮均在视口内，弹窗矩形未越界。

## 7. 功能入口原则

1. 对局中高频/紧急（暂停）必须 1 次点击可达，放顶栏；静音/音量/动画/节奏属偏好配置，放设置（设置经「更多」2 击进入）。
2. 不可撤销（退出、投降、重开）不放常驻首位，必须二次确认；投降/退出收进「更多」最下方并用分隔线与常用项隔开。
3. 对局界面常驻图标总数不超过 3 个（当前正好 3 个：暂停/战报/更多），且 323×792 下不遮挡座位、手牌、按钮栏；未通过 5 视口 `layout_check.js` 前不得新增常驻入口。
4. 选目标 pick-bar 替换顶栏时，必须在 pick-bar 内保留暂停入口，不能因隐藏顶栏丢失暂停能力。
