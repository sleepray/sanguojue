## 结论

| 项 | 内容 |
|---|---|
| 现象 | `out/apk/6x_response.jpg` 中央【借刀杀人】书法「借刀」只露下半部分；卡图顶部被 cover 裁掉 |
| 根因 | 手机横屏 `.played-card` 在 `css/b4-hud.css:56` 用 `width:72px; height:var(--pc-h)`（792 66、997 86），宽高比 0.84/1.09；手牌 `.hand-card` 是 68×90=0.756；卡图 `object-fit:cover`（`css/style.css:538`）按容器宽度放大，图片渲染高度 96.7>84，上下各裁约 6px，书法顶部被切。平板 92×128=0.719 与手牌 96×133=0.722 接近，故主要发生在手机横屏。 |
| 修法 | 中央牌宽度改为 `calc(var(--pc-h) * .75)`，使图片容器宽高比与手牌一致（997 65×86→图 63×84；792 50×66→图 48×64，均为 0.75）。保留高度 0.9–1.0 手牌高（997 86/90）、出牌人 12px、底部牌名+点数框；底部牌名在 997 缩到 7.5px 一行，792 四字两行，避免点数框压字。`played-card` overflow 保持 visible，img 容器高度=卡高-2px 边框，顶部不再被额外裁切。 |
| 验证 | 中央 img `naturalWidth=126>0`；`img.clientWidth/clientHeight` 63/84=0.750，手牌 66/88=0.750；`imgTop>=cardTop`；卡容器 overflow=visible。`qa_e2e` T48 已补 naturalWidth、比例、img 高度、顶部不越界、overflow 断言。截图见下。 |
| 截图 | `played_jiedao_997x448.jpg`、`played_jiedao_792x323.jpg`（求桃响应，中央借刀+杀） |
| 回归 | `QA_ONLY=T48,T49 node tools/qa_e2e.js`：T48 PASS（含新增 naturalWidth/比例/高度/顶部断言）、T49 PASS；`ui_probe --viewport 997x448`：23 PASS/0 FAIL。412×915 仍有一条既有选目标确认按钮 FAIL（与中央牌改动无关）。 |
