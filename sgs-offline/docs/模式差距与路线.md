## 2. 为什么不是“加个按钮”就行

当前引擎把“身份局”写死得比较多，新增模式需要先做抽象：

1. **`js/game.js`**
   - `MODES` 只有 roles 数组；没有“队伍/阵营/胜利条件”抽象。
   - `winner`/击杀奖惩/主公技按 `lord/loyalist/rebel/renegade` 写死。
   - 1v1 的摸牌、手气卡、牌堆剪裁是专门分支。
2. **`js/ai.js`**
   - 关系判断基于身份（主忠/反/内），没有“队友/敌人/主公”通用关系。
   - 2v2/3v3/国战需要 `team` 与队友保护、集火、配合。
3. **`js/ui.js` / `css`**
   - 座位布局按 8/5/2 写死（`POS_8/POS_5/POS_1`）。
   - 没有队伍颜色、队友标记、Ban/Pick 界面、国战双将/暗将 UI、PvE Boss 血条。
4. **`js/data.js`**
   - 只有标准+军争 160 张；斗地主/国战/活动场需要独立牌堆与将池。
5. **服务端/联机**
   - 排位、匹配、观战依赖联网；单机只能做本地段位/回放。

## 3. 建议优先级

### ~~P0：2v2（4 人）~~ 已完成
- 复用 8 人引擎，新增 `team` 字段（0/1）、队伍胜利条件（击杀对方两人）。
- 4 个座位、队友高亮、队友 AI 保护/配合。
- 选将各 3 张，禁将可选。
- 预计：3–5 天。

### ~~P0：3v3（6 人）~~ 已完成（简化胜利条件）
- 在 2v2 的队伍抽象上扩展为 3 人队；暖主/前锋/主帅座次。
- 选将/禁将流程、击杀主帅获胜。
- 6 人座位布局 + 队伍颜色。
- 预计：1–2 周。

### ~~P1：斗地主（3 人）~~ 已实现（简化版）
- 专属牌堆（去掉部分牌/加地主牌）、叫地主/抢地主、倍率、春天。
- 3 人座位与地主标识。
- 预计：1 周。

### P1：国战（多人）
- 双将、暗势力、珠联璧合、野心家、鏖战。
- 需要最大的规则/ UI 改造；建议在队伍抽象稳定后做。
- 预计：3–4 周。

### P2：活动场 PvE
- 虎牢关/神武再世/十殿阎罗/守卫剑阁：Boss AI、阶段脚本、专属牌堆/奖励。
- 每个剧本 1–2 周，建议先做**虎牢关**（3 人、规则相对独立）。

### P2：本地排位/残局/回放
- 本地段位与赛季不需要服务器；回放可复用 `game.logs` + 初始 seed。
- 残局/新手引导适合做教学。

## 4. 我建议的下一步

先做 **2v2（4 人）**，它是投入最小、能验证“队伍/队友 AI/4 人布局”三件事的模式；跑通后再扩 **3v3（6 人）**。国战和斗地主规则差异大，放在队伍框架稳定之后；PvE 活动场最后做。

如果只想加一个“最像原版”的模式，优先 **3v3**；如果只想最快多一个可玩模式，优先 **2v2**。
