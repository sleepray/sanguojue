## 5.3 App 特有项结果

### 暂停面板

- 入口：设置面板底部「暂停游戏」（`index.html:326`），点击后先关设置再调 `SGS_APP_PAUSE(true,{keepAudio:true})`（`js/main.js:666-674`），符合不变量 4。
- 冻结：暂停 1.8s 后读秒仍 `剩余 90s`；点「继续游戏」后 1.5s 为 `剩余 89s`，从剩余时间继续，不重置、不跳秒。
- 底层不可点：遮罩 `position:absolute; inset:0; z-index:500`（`css/style.css:3441-3446`），实测 `elementFromPoint` 命中 `resume-card`，不是顶栏/手牌按钮。
- 选择状态：暂停前打开选牌弹窗并选 1 张，暂停→继续后仍 `已选 1 / 1`；响应弹窗 `剩余 45s` 与提示条保持不变；未出现重复弹窗。
- 音频：手动暂停保留 BGM（`keepAudio:true`），暂停遮罩文案为「牌局与读秒已暂停，背景音乐继续」（`js/main.js:652`）。

### 后台恢复

- 壳层：`onPause/onStop/onWindowFocusChanged` → `pauseForBackground()` → 先执行 `SGS_APP_PAUSE(true)`，80ms 后再 `pauseTimers()/onPause()`（`MainActivity.kt:177-205`）；回前台只 `resumeTimers/onResume`，不自动恢复引擎（`MainActivity.kt:168-175`）。
- 网页兜底：`visibilitychange` 且 `document.hidden` 时只调 `SGS_APP_PAUSE(true)`（`js/main.js:657-660`）；恢复必须由玩家点「继续游戏」（`js/main.js:662-665`）。
- 实测（以 `SGS_APP_PAUSE(true)` 模拟切后台，同一函数入口）：
  - 静音态：暂停 5s 后点「继续游戏」→ `SGS_AUDIO.enabled === false`，306 个 `Audio` 元素全部 `paused`，BGM `currentTime` 不前进。
  - 非静音态：暂停 5s 后点「继续游戏」→ `bgm_battle.mp3` 恢复播放，`currentTime` 1.59s，无自动快进。
- 限制：headless 无法真正触发 Android 生命周期，壳层路径以代码 + 同一 `SGS_APP_PAUSE` 入口验证；真机切后台需 A/集成阶段补一次。

### 横竖屏切换

- 实测 412×915、915×412、800×1280、1280×800：`#btn-quit` 均在视口内；退出确认弹窗矩形未越界；设置面板打开后完整落在视口内（915×412 为 `[585,52,330,360]`）；无横向滚动（`scrollWidth == innerWidth`）。
- 360×640 补充：设置面板 `[30,84,330,556]`，右/下边贴合视口；暂停卡 230×138 居中；「继续游戏」111×37 可点。
- 结论：布局重排后按钮/弹窗不错位；竖屏小宽度下设置面板靠右贴边，符合预期。

### 刘海/挖孔与手势导航条

- `index.html:5` 使用 `viewport-fit=cover`；`css/style.css:2313-2318` 及 2346/2351-2352/2373/2378/2407-2408/2444/2448/2471-2472/2509-2512/2515-2516 等使用 `env(safe-area-inset-*)`，顶部座位与底部按钮栏均避让。
- 结论：safe-area 已覆盖，无需改动。

### 系统字体放大（textZoom）

- `MainActivity.kt:90` 固定 `textZoom = 100`，系统字体放大不会改变 WebView 文本缩放。
- 结论：通过，无需人工决策。

### 静音开关（本轮实现）

- 实现：设置面板新增「静音 / 音乐与音效」开关（`index.html:302-308`），`js/main.js:54-67` 用 `SGS_AUDIO.enabled` 切换，`js/main.js:675-678` 绑定 `change` 并持久化到 `localStorage['sgs.settings.v1']` 的 `mute` 字段；启动时 `js/main.js:76/681` 恢复。
- 触控：`.switch-mute` 热区 44×44（`css/ui-107.css`），真实鼠标点击 label 中心可切换；视觉轨道仍 40×22。
- 音频层修复（`js/audio.js`）：
  - `resume()` 在 `state.enabled === false` 时直接返回，不再恢复 BGM（`js/audio.js:383-385`）。
  - `enabled` setter 仅在 `!state.suspended` 时恢复 BGM（`js/audio.js:463`），避免暂停遮罩下提前出声。
- 验收实测（a–d）：
  - a) 静音 → 后台暂停 5s → 点「继续游戏」：`SGS_AUDIO.enabled === false`，BGM 及全部音效 `paused`（播放中列表为空）。
  - b) 解除静音 → 播放战斗 BGM → 后台暂停/恢复：`bgm_battle.mp3` 恢复播放，`currentTime` 1.59s。
  - c) 刷新页面后：`enabled === false`，`sgs.settings.v1` 为 `{"mute":true}`，设置面板复选框 `checked === true`。
  - d) 设置面板打开时 `SGS_BACK()` 返回 `true`，面板关闭（`class` 变回 `settings-panel`）。
- 已知小项：`enabled=false` 只暂停 BGM，已经在播的短音效（如 `wanjian_male_1`）会自然播完（<1s），不做强制截断；不影响「静音后无音乐、后台回来不自动有声」的验收。

## 5.4 统一排布规则摘要

完整规则见 `docs/UI排布规范.md`，要点：

1. 弹窗按钮统一「取消/放弃」在左、「确认/打出」在右；同类弹窗复用同一结构与文案。
2. 同一界面同权重常驻按钮≤3 个；危险操作（投降、退出、重开）必须二次确认且不放在常驻首位。
3. 可点区域≥44×44 CSS px，文字≥12px；开关类整行 label 可点，不能只让 13×13 的 input 可点。
4. 暂停/后台统一走 `SGS_APP_PAUSE(paused, opts)`：后台冻结引擎、读秒、音频；手动暂停保留 BGM；恢复只能由玩家点「继续游戏」。
5. 静音与暂停分离：静音只关音频总开关并持久化，不改变暂停态；静音后切后台再回不得自动有声。
6. 返回键只关闭「可关闭的最上层」；强制选择弹窗、退出确认、暂停遮罩不关闭；只有主菜单返回 `false`。
7. 新常驻入口必须通过 5 视口 `layout_check` 才能保留，否则撤回并写方案；对局界面新增常驻图标≤3 个。
