### 1v1 原版规则（原文摘录）

`AppCfgData/list3.sgs` → `hd_special1v1.root.Common[0].des`：

> 1. 本模式为 1v1 面杀而提供的练习模式，可以邀请好友或对抗小杀
> 2. 模式人数为两人，分别是忠臣和反贼，率先击败敌对阵营的一方获胜
> 3. 游戏开始后抽取身份，忠臣为 1 号位，反贼为 2 号位，1 号位首轮摸牌数 -1 并可使用 1 次手气卡，2 号位初始手牌数 +1 并可 2 次手气卡
> 4. 卡牌为独立牌堆，在军争牌堆基础上移除了包括【木牛流马】在内的 52 张牌
> 5. 将池为独立将池……
> 6. 进入条件……

同配置还有 `generalNum: 4`，即**每人 4 张候选将**。

### 当前 1v1 实现映射

| 原版 | 实现 |
| --- | --- |
| 2 人，忠臣 1 号位 / 反贼 2 号位 | `mode:'1v1'`，seat0 = 忠臣，seat1 = 反贼 |

## 4. 已知简化（规则层）

1. 蛊惑、化身、巧变仅实现基础效果，未做完整"声明/质疑/化身替换/移动场牌"交互。
2. 无懈可击按整张锦囊逐目标询问，未做"逐目标分别抵消"的完整链。
3. 1v1 牌堆用标准 108 张替代原版"军争剪裁 108 张"。
4. 手气卡、MVP/战功、皮肤、动态立绘不在范围内。
5. AI 仍使用身份全知做目标选择（单机体验优先），后续可加"信息隐藏"难度选项。

## 5. 自查结论

- 节奏：已按原版动画 0.367s + 阶段 1.5–2s 的证据重做，默认档接近原版。
- 模式：补齐了原版有明确文案的 1v1 单挑；3v3/国战不在本期范围。
- 素材：卡牌/座位立绘全量；3 名武将缺大图，已兜底。
- 规则：主流程可完整跑通；上述简化项会在 README 与游戏内说明中标注。
