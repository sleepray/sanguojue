## 4. 暂停与 pick-bar

### 4.1 顶栏暂停

- 入口：`#btn-pause` → `pauseGame()`（`js/main.js:521-526`）→ `SGS_APP_PAUSE(true,{keepAudio:true})`。
- 实测（412×915，真实开局等到玩家读秒）：`剩余 90s` → 点暂停 2.2s 后仍 `剩余 90s` → 点「继续游戏」1.4s 后 `剩余 89s`；遮罩 `resume-overlay is-on`，副标题「牌局与读秒已暂停，背景音乐继续」。
- 323×792 由 `tools/ui_probe.js` 复跑同样通过（90→90→89）。

### 4.2 选目标 pick-bar 保留暂停

- 现状：选目标时 `body.is-table-pick` 会把顶栏 `visibility:hidden`（`css/style.css:3663`），pick-bar 顶部替换顶栏（`top: calc(4px + env(safe-area-inset-top))`）。
- 方案：**在 pick-bar 内新增暂停按钮**（`data-pick="pause"`，`js/ui.js:2981`），点击走 `triggerPause()`（`js/ui.js:2991`），不依赖被隐藏的顶栏。
- 尺寸：323 实测 51×44，412 实测 44×44；pick-bar 高 44，按钮 ≥44×44、字号 11/12px。
- 选择状态保持：真实开局注入 chooseTargets → 选 1 个目标（`1 / 1`）→ pick-bar 内暂停 → 继续：仍 `1 / 1`，pick-bar 保留，无重复弹窗。
- 截图：[412_pickbar.png](../out/ui/b2/412_pickbar.png)。

## 7. tools/ui_probe.js

用途：把返回键、暂停、静音、pick-bar 暂停整理成可复用探测，供任务 4 纳入 qa 流程。

```
node tools/ui_probe.js
node tools/ui_probe.js --viewport 323x792
node tools/ui_probe.js --base-url http://127.0.0.1:8899/ --chrome "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
node tools/ui_probe.js --json
```

- 退出码：0 = 全 PASS/SKIP；1 = 有 FAIL；2 = 环境不可用；无 Chrome 时输出 `SKIP` 并退出 0。
- 覆盖：
  1. SGS_BACK 矩阵：主菜单/对局/更多/设置/战报/暂停遮罩/选牌弹窗/结算/选将。
  2. 暂停：真实开局等到读秒，验证冻结与恢复。
  3. 静音：开关写入 `sgs.settings.v1`、切后台再回来不自动有声、刷新持久化、解除恢复。
  4. pick-bar：真实开局注入 chooseTargets，验证暂停按钮 ≥44 且遮罩打开、选目标条保留。
- 实测结果：323×792、412×915 均 **16 PASS / 0 FAIL / 0 SKIP**。

## 9. 遗留 / 风险

1. **qa_e2e.js 旧选择器**：`tools/qa_e2e.js` 仍用真实鼠标点 `#btn-settings`/`#btn-trust`/`#btn-save`/`#btn-surrender`/`#btn-quit`，这些现在在隐藏菜单里，真实点击会失败；需在任务 4 改为「先点 #btn-more 再点菜单项」，或改用 `element.click()`。本轮写入范围不含该文件，未改。
2. **A 的 layout_check.js 暂停场景**：第 324 行仍点已删除的 `#btn-pause-game`，会报「场景执行失败」P1；已消息 ui-dev 改为 `#btn-pause`。设置场景点隐藏的 `#btn-settings` 仍可用（DOM click 不受 display:none 影响）。
3. **pick-bar 验证方式**：真实牌局中 chooseTargets 触发不稳定（60s demo 未出现），ui_probe 采用「真实开局 + 注入 chooseTargets 请求」验证同一 UI 路径；真实牌局触发需后续用具体锦囊/技能补一条。
4. **结算按钮高度 35px**：低于 44 基线，但不在任务 1「顶栏/菜单/设置」范围内；A 的 layout_check 交互选择器未包含结算按钮，暂不列为 P1。
5. **菜单打开时覆盖牌桌**：属临时浮层（z-index 210），关闭即恢复；未做点击遮罩层，仅点外部关闭。
6. 真机 Android 返回键/切后台未在本轮覆盖（任务 5 负责）。
