# 整体节奏 / UI / 操作 / 声音 全量对照

> 对照：三国杀OL 3.7.4 解包配置与 prefab + 当前单机版
> 本轮目标：不再单独调某个 AI 等待，而是把「AI 决策 + 阶段停顿 + 托管」作为一套整体节奏；同时全量自查 UI/操作/声音。

## 1. 整体节奏

旧配置：AI 每次决策固定 **1000ms**，阶段停顿只乘 **1.0**，托管 AI **260ms**；三档只是改 AI 数值（1800/1000/550），阶段动画不变。实际对局里阶段与出牌衔接偏快。

新配置（整套缩放）：

| 档位 | AI 决策 | 阶段/演出停顿 | 托管 AI |
|---|---:|---:|---:|
| 慢 | 2200ms | ×1.70 | 760ms |
| 标准 | **1500ms** | **×1.35** | **560ms** |
| 快 | 850ms | ×0.80 | 380ms |

- `Game.pause()` 仍保留各阶段原始值（准备 300/判定 450/摸牌 350 等），由统一 `pauseFactor` 缩放。
- `SGS.AI.delay()` 现在接受倍率：出牌决策 1.0、响应/选牌 0.55。
- 设置抽屉切节奏会**同时**改当前对局的 `paceFactor` 与所有 AI 速度，不再只改 AI。
- 实测标准档 8p 连跑 3 个 AI 回合：约 12.9s / 14.2s / 19.3s（含一回合多张牌与响应），比旧档明显放缓。

## 3. 操作对照

- 铁索连环：不选目标=重铸摸 1；选 1–2 人横置/重置；属性伤害传导并重置；已修“单人横置不重置/目标残留横置”。
- 流离/天香等 `chooseTargets`：不再弹整屏 modal，改为桌面点头像 + `pick-bar`。
- 2v2/3v3：蓝/红队、交替座次、每人 3 候选、消灭对方全队；击杀奖惩关闭。
- 斗地主：3 人、地主 1v2、地主 +2 体力/起手 6 张、地主阵亡农民胜、两农民阵亡地主胜。
- 存档：人类回合开始自动快照；顶栏保存；主菜单继续；刷新后可续跑。
- 选牌弹窗点击不再重建 `fadeIn` 全屏闪（`is-refresh` + `animation:none`）。

## 4. 声音对照

- 卡牌语音 99 条 / 27 张牌：按原版 `cardmusic` 的 **skillID** 重新映射；杀 4 条、火杀/雷杀/闪各 4 条。
- 武将语音 1361 条 / 54 将：技能、阵亡、皮肤变体。
- 修复：旧 PWA 缓存索引、无效静音解锁探针、装备无声音、延时锦囊无事件。
- 修复：技能语音按战报发动者名字找 owner，避免同技能多人播错。
- 修复：移除 recent damage 的通用掉血声，避免与武将受伤语音叠加。
- 缺口：16 张牌本地包无语音；31 周泰/32 张角/33 于吉无语音；无「杀/闪/桃」角色人声（原版走 CDN，本地包没有）。
- 索引 `assets/audio_index.json?v=3`，Service Worker 对 JSON network-first。
