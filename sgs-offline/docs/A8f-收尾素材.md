## 2. 高分辨率手机（1067×480 / 1280×576）

### 2.3 等比缩放
- JS 在 `init`/`resize` 设置 `--ui-scale = min(1.3, max(1, min(vw/997, vh/448)))`。
- 997×448 及以下不放大；1067×480=1.071；1280×576=1.284；792×323 保持 1（不缩小）。
- CSS 只对 `(min-width:1000px) and (max-height:640px)` 用实际尺寸变量放大：顶栏、玩家区、头像、手牌、座位、装备图标、中央牌、动作按钮、字号；不使用 transform，`getBoundingClientRect` 为真实布局尺寸。
- 验证：997/1067/1280 截图比例一致，1067/1280 的座位/手牌/按钮明显增大，997 基线不变。
