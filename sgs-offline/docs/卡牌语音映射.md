## 结论先说

v1 的映射前提是错的：它把 clip 名的首段数字当成 `CardsBook.id`，
而原版实际使用的是 **skillID**。两者只在基础牌 1~7 上恰好同序，
所以「杀/闪/桃」看起来对，到 `50=裸衣`、`200=仁王盾`、`201=寒冰剑` 就全错位。
这也是用户看到「部分语音和牌不一致」的直接原因。

## 关于「出【杀】没有声音」

按影响程度排序，逐项给证据：

**1. 播放键名 / UI 调用：已排除。**
`js/game.js` 造牌时 `name` 存的是拼音键（`['sha','spade',7]` → `{name:'sha'}`），
`js/ui.js` 在 `ev.kind==='use'` 时调用 `sfx('playCard', ev.card)`，
因此 `SGS_AUDIO.playCard('sha')` 收到的键是正确的，不是 `'杀'` 也不是对象。

**2. 声音本身：不是静音，但「短 + 轻 + 尾部大段空白」。**
`杀` 的原始 clip 有效语音只有 0.29~0.69 秒（其它牌普遍 0.9~2.0 秒），
而声明时长 1.9~3.3 秒——中间 1.5~2.7 秒是数字静音填充。
v1 直接把这些文件整段转码，结果就是「点一下，响 0.3 秒，剩下两秒全是静音」，
在环境噪音或音量偏低时很容易被判成「没声音」。

**3. 映射错位：确实存在，但表现为「语音和牌不一致」。**
v1 的 `sha` 池共 **16 条**，实际构成是：

| 池内内容 | 条数 | 真实归属 | 是否正确 |
| --- | ---: | --- | --- |
| 无属性后缀的 `1.x.x` | 4 | 普通【杀】 | ✅ |
| `1.x.x.6` | 4 | 【火杀】 | ❌ 应归 huosha |
| `1.x.x.7` | 4 | 【雷杀】 | ❌ 应归 leisha |
| `1.x.x.11` | 2 | 【冰杀】（本作没有） | ❌ 应剔除 |
| `50.x` | 2 | 技能「裸衣」 | ❌ 完全是别的语音 |

也就是说 **12/16 条是错的**，只有 4 条真正是普通【杀】。
这也直接解释了用户反馈的「部分语音和牌不一致」——出杀时随机抽到火杀、雷杀甚至裸衣的语音。

**4. 真正的静音文件：不存在。** 202 条 clip 全部有有效语音（有效段 RMS 最低也有 -20.1 dB）。

## 【无懈可击】为什么没有声音

**素材没有问题**：`wuxie` 有 4 条确认语音（2 男 2 女），路径存在、时长 1.0~1.3 秒。
问题出在**事件链**：`assets` 有了，但 UI 从来没被通知去播。

现状（读代码确认）：

1. `js/ui.js` 里唯一触发卡牌音效的地方是 recent 扫描：
   `if (ev.kind === 'use') { sfx('playCard', ev.card); ... }`（约 2420 行）
2. 普通牌在 `js/cards.js` 使用时会 `this.recent.push({kind:'use', card, targets})`（237 / 247 / 273 行）
3. 但【无懈可击】走的是响应流程 `isNullified()`，只做了 `this.log(..., 'wuxie')`（`cards.js` 381 行），
   **没有 push recent**，所以 UI 收不到 `kind:'use'`，自然不播。

**最小改法（只需改 `js/cards.js` 一处，3 行）：**

```js
// js/cards.js, isNullified() 内，紧跟 this.log(...'wuxie') 之后
this.recent.push({ kind: 'use', seat: played.q.seat, card: 'wuxie', targets: [] });
if (this.recent.length > 200) this.recent.shift();
```

为什么这样就够：

- `targets: []` 让 `flashArrows()` 直接返回（`ui.js:779` 有空数组短路），只出声、不会画错箭头；
- 与 `cards.js:237`（无中生有这类非指向牌）写法一致，属于既有约定；
- 不用改 `ui.js`，也不用改 `audio.js`；
- `recent` 只有 UI 消费（`game.js:59` 注释「UI 动画用」），补事件不影响规则结算。

若要区分「无懈是响应、不是出牌」，也可 push `{kind:'wuxie', seat}` 并在 `ui.js` recent 循环里加一个
`else if (ev.kind === 'wuxie')` 分支——但这是两处改动，非最小方案。

## 接入方式

```js
SGS_AUDIO.playCard('sha');   // assets/audio/card/sha_1.mp3 … 随机一条
SGS_AUDIO.playCard('huosha');
SGS_AUDIO.playCard('leisha');
```

若某张牌没有对应语音（见上表），请回退到 `equip` 或通用 `sfx_card_play`。
