## 3. 不可回退的行为约定（不变量）

1. **AI 不透视身份**：只有主公和已 `revealed` 的武将互相可见；反贼彼此不再认作队友。
2. **1v1 摸牌**：只有 1 号位首回合少摸 1 张，标记存 `p.duelFirstDraw`（不能放 `p.flags`，每回合会被清）。
3. **后台必须冻结**：引擎 `setPaused` + 倒计时冻结 + 音频挂起；回前台只恢复 UI，不解暂停。
4. **手动暂停保留音乐**：`keepAudio: true` 只冻结逻辑与倒计时。
5. **长按看武将**才显示介绍，单击不出介绍。
6. **手牌再点一次取消**，卡牌落回正常高度，不能有 hover 上移残影。
7. **暗手牌选择只能看到牌背**，选完才翻真牌。
8. **五谷结束必须清层**（含被无懈/无人取走的情况）。
9. **8 人/3v3 顶部座位与中央出牌区不重叠**（平板竖屏 720×1280 起验证）。
10. **濒死求桃逐个求**，顺序与存活座位一致。

## 4. 关键实现点（代码地图）

```
js/game.js    状态机；mulliganPhase（已停用）/ judge / dying / tuxi / pickCardFrom
js/cards.js   卡牌结算；wuguEnd、handReveal、groupWaiting 事件源
js/skills.js  技能；pindian() 结构化事件 + 1700ms 等待；连营条件含装备
js/ui.js      渲染与弹窗；chooseHiddenCard、showHandReveal、showRescue、showPindian
js/main.js    SGS_BACK() 返回栈、SGS_APP_PAUSE(paused,opts)、暂停按钮
js/audio.js   suspend/resume 挂起态
sgs-offline-apk/app/src/main/kotlin/io/sanguoduel/offline/MainActivity.kt
              全屏/刘海、后台暂停、onResume 不解暂停、异步返回键
```

新增/关键 API：

- `SGS_APP_PAUSE(paused, {keepAudio})`：唯一暂停入口，原生与网页共用。
- `SGS_BACK()`：返回 `"true"` 表示已消费，原生才不 `finish()`。
- `chooseHiddenCard` 请求：`{ type:'chooseHiddenCard', player, count, reason }`。
- `afterLoseCards(p, cards, fromHand)`：失去牌统一钩子，连营/其他触发都走这里。
