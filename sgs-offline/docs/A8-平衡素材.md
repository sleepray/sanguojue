# A8 — 1.0.8 AI 阵营平衡统计素材

## 1. 工具

`tools/balance_bench.js`（新建；不改产品 AI/UI）：

```bash
node tools/balance_bench.js --mode=5p --games=400 --seed=1000 --level=normal
node tools/balance_bench.js --mode=8p --games=400 --seed=1000 --level=normal --json
```

- `--mode` 5p / 8p；`--games`；`--seed` / `--startSeed`；`--level` easy/normal/hard；`--json`。
- 每局创建 `SGS.Game({mode,seed,cardPack:'full',humanSeat:-1})`，座位全部 `SGS.AI({speed:0,level})`；不进入 UI。
- 真实 `p.role` 只在统计工具中读取；AI 永远只走自己的公开信息推断（不变量 1）。
- 结果 JSON：`out/balance/<mode>_<level>_<seed>_<games>.json`；含 `summary` 和每局 `results[]`。
- 汇总表同时打印；`--json` 输出 `{file,summary}`。

### 指标定义

| 指标 | 定义 |
|---|---|
| 胜方阵营 | `winner` lord→主公方，rebel，renegade；null/超时=平局 |
| 各阵营首个阵亡回合 | 同阵营（主忠/反贼/内奸）中最早 `p.deathTurn` |
| 主公阵亡回合 | `lord.deathTurn` 分布（1-5/6-10/11-15/16-20/21-30/31+） |
| 误伤率 | 伤害/削弱动作（杀、火杀、雷杀、决斗、火攻、过拆、顺手、乐、兵、强袭等）的目标中，真实同阵营目标数 / 全部目标数；另给动作级。按行动者阵营细分 |
| 救援率 | 主公濒死时，真实忠臣/内奸手中有【桃】的询问次数中，实际使用桃成功次数；按角色细分 |
| 推断准确率 | 每回合末每个 AI 对其他存活角色 `friend/enemy`（跳过 neutral）与真实阵营的一致性；分观察者阵营；首次非 neutral 回合分桶 |
| 内奸存活到最后两人 | 终局内奸仍存活且全局存活人数≤2 |
| 内奸最终名次 | 1=内奸胜；存活=存活人数；死亡=总人数-死亡顺序+1 |
| 风格 | 若 C 提供 `game.agents[seat].style`，工具直接读取并按风格聚合（预留） |
| 95% CI | Wilson score interval，z=1.96 |
