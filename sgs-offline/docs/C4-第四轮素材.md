## 2. 槽位、写入时机与迁移

### 2.1 存储键与结构

| 键 | 用途 | 说明 |
|---|---|---|
| `sgs.save.auto` | 自动档（滚动覆盖） | 每个回合开始写一次，含 AI 回合（`js/game.js:381-385`） |
| `sgs.save.slot1` | 手动槽 1 | 「更多 → 保存」或存档面板写入 |
| `sgs.save.slot2` | 手动槽 2 | 同上 |
| `sgs.save.slot3` | 手动槽 3 | 同上 |
| `sgs.save.v1` | 旧版单档（1.0.6/1.0.7 早期） | 首次启动迁移到 auto 后删除；损坏则清除并提示 |

信封（v2）：

```json
{ "v": 2, "kind": "auto|manual", "time": 1794884492166,
  "mode": "8p",
  "meta": { "mode": "8p", "turn": 3, "general": "关羽", "time": 1794884492166 },
  "snapshot": { "...": "game.snapshot()" } }
```

- 自动档写入：`saveAuto()`（`js/main.js:238`）；失败不覆盖上一次仍可用的 autoInfo。
- 手动保存：保存 `lastSnapshot`，即最近一次「回合开始」快照（`js/main.js:289`），不是点击瞬间；打开面板时文案明确写「保存本回合开始时的进度」。
- 读手动档后：`loadGame()` 先 restore，再 `saveAuto(game.snapshot(), {silent:true})`，自动档从该局继续滚动（`js/main.js:395-397`）。
- 结束/投降/退出判负：`clearAuto()` 只删 auto，`slot1–3` 保留（`js/main.js:943/962`）。
- 删除槽位需二次确认（按钮变「确认删除」）；覆盖槽位同样二次确认（「确认覆盖」，4s 未确认还原）。

### 2.2 旧档迁移与兼容

1. `refreshAllSaves()` 先读 auto/slots；损坏键删除并记录「存档损坏，已清除」。
2. `migrateLegacySave()`（`js/main.js:266`）：
   - `sgs.save.v1` 结构有效且 auto 不存在 → 生成 v2 auto 信封，删除 v1；
   - auto 已存在 → 只删 v1，不反向覆盖；
   - v1 损坏 → 删除并提示「旧存档已损坏，已清除」。
3. 1.0.6 样本：`snapshot` 与当前 v1 结构一致，但没有 `rngState`；恢复时跳过 RNG 状态，按 `seed` 重建序列，不崩溃。已用 `git show c1ebe84:sgs-offline/js/{game,data,skilldesc}.js` 在临时目录载入 1.0.6 引擎生成真实样本（4405 字节，md5 `1537efae5d61fef88fb0b586fea77961`；snapshot 键 22 个、无 `rngState`）；用当前引擎直接 `restore` 该样本得到 players=8 / turn=5 / currentSeat=2 / revealed=true，无异常。T55 中动态构造的 fixture 与该旧样本字段结构一致（仅牌局数值不同），验证迁移 + 继续 + revealed 可见。
4. 损坏/缺字段（无 players、无 mode、JSON 语法错误）：清除对应键、隐藏继续按钮、toast「存档损坏」；不会白屏（T55）。

## 5. APK 存档验证操作步骤（供任务 3 执行）

包名：`io.sanguoduel.offline`；设备 `emulator-5554`；本机服务 `http://127.0.0.1:8899/`。

### 5.1 强杀后读档

1. 启动 App，开始一局（建议 5 人快节奏），等到顶栏出现「已自动保存」；记录主菜单/对局中可见的 `模式、回合、自己的武将、手牌数`。
2. 返回桌面或直接 `adb -s emulator-5554 shell am force-stop io.sanguoduel.offline`。
3. 重新打开 App，主菜单应出现「继续游戏」，下方显示「模式 · 第 N 回合 · 存档时间」；截图。
4. 点「继续游戏」，应为强杀前最后一次「回合开始」的快照：模式/人数/武将/回合/手牌与记录一致（允许比强杀瞬间早一个回合内）。
5. 截图命名 `out/apk/4x_save_force_stop.png`、`4x_save_continue.png`。

### 5.2 覆盖安装后存档保留

1. 先在一局中等到「已自动保存」，并手动保存一个槽位（更多→保存→槽 1）。
2. `adb -s emulator-5554 install -r out/apk/<新包>.apk`。
3. 启动 App：继续游戏仍可见；读取存档面板应有自动档 + 槽 1；读槽 1 可正常进入对局。
4. 截图 `4x_save_reinstall.png`（面板含自动+槽 1）。

### 5.3 切后台后存档不丢

1. 对局中等到「已自动保存」；按 Home 切后台（或 `adb shell input keyevent KEYCODE_HOME`），停留 ≥5s。
2. 回到 App：自动档仍在（如显示暂停遮罩，点「继续游戏」后对局正常；倒计时不跳秒）。
3. 退出到主菜单（或重开 App）：继续游戏仍可见，读档内容一致。
4. 截图 `4x_save_background.png`。
