# 三国杀·单机版 — 项目现状（2026-11-13）

## 一句话

用《三国杀OL》3.7.4 安装包里的静态素材，重新实现的**纯离线网页单机版**：原生 HTML/CSS/JS，无框架、无后端、无网络请求；和 AI 打身份局或单挑。

## 运行

```bash
cd sgs-offline
python3 tools/serve.py 8899
# 浏览器打开 http://127.0.0.1:8899/
```

macOS 可双击 `启动游戏.command`。发布包：`artifacts/sgs-offline-<日期>.zip`（约 41 MB）。

## 代码结构

```
index.html / css/style.css        UI 外壳
js/data.js                        160 张牌 / 57 将 / 技能文案 / 1v1 禁牌表
js/game.js                        游戏状态机：回合、判定、伤害、濒死、胜负
js/cards.js                       卡牌使用与结算、响应询问、装备/延时锦囊
js/skills.js                      技能实现（主动/触发/转化/觉醒）
js/ai.js                          AI：身份判断、出牌评分、响应
js/ui.js / js/main.js             DOM 渲染、请求弹窗、菜单、音频、托管
js/audio.js                       音效/BGM（缺失静默降级）
assets/                           卡图、立绘、音频
tools/                            抽包、数据自检、无头对局、审计/QA 脚本
docs/                             原版对照、技能审计、修复记录、QA 报告
```

引擎是异步状态机：每次需要决策时 `await agent.decide(request)`；人类 agent 的 Promise 由 UI 解析。AI 与人类共用同一套请求/应答契约。

## 离线（PWA）

首次打开会由 `sw.js` 缓存 356 个文件（约 43MB）；之后停掉本地服务器、断网刷新仍可进菜单、选将、开局。修改前端后重新运行 `python3 tools/build_sw.py` 更新缓存版本。

## 整体节奏

- 三档为整体缩放：AI 决策 / 阶段停顿 / 托管一起变；标准=1500ms + ×1.35 + 560ms，慢=2200ms + ×1.7，快=850ms + ×0.8。
- 详见 `docs/整体节奏与全量对比.md`。

## 已实现的原版功能对照

- 身份局 5/8 人：身份分配、主公+1 体力、击杀奖惩、暗身份、身份标记（点击徽记）。
- 1v1：忠臣 1 号位/反贼 2 号位、首轮少摸、2 号位起手 +1、4 张候选、军争剪裁 108 张。
- 2v2/3v3：蓝队/红队双队、交替座次、每人 3 张候选，消灭对方全队获胜；队友 AI 自动配合。
- 斗地主：3 人、叫地主/抢地主、倍率 ×1/×2/×4、地主 +2 体力/起手 6 张、地主阵亡农民胜、两农民阵亡地主胜。
- 身份 UI：按原版 `GetFigureColor` 六色显示（主公/忠臣/反贼/内奸 + 地主/农民）。
- 存档：每个蓝队/红队或身份局的人类回合开始自动快照；顶栏「保存」、主菜单「继续游戏」，读档从该回合开始重开。
- 对局：判定区、装备区（对手装备显示真实牌面缩略图）、延时锦囊、无懈链、濒死求桃、翻面/横置/铁索传导、属性伤害。
- 节奏：出牌动画 0.367s、阶段停顿、AI 全决策节流、慢/标准/快三档。
- 工具：手气卡（弹窗内展示手牌）、托管、投降、返回确认、倒计时、AI 思考指示、MVP 结算、战报、BGM/语音。
- AI 难度：简单/普通/困难，主菜单可选，影响出牌与响应策略。
- 方向线：对照原版 DirectionLine 的橙色实心光带 + 白热芯；**金龙仅在武将等阶 `gradation>=4` 时显示**（原版 `MinLineEffectGradation=4`）。单机默认 0 阶，金龙关闭；要给某将开启，在 `js/data.js` 的 `GENERAL_GRADATION` 填 4（已用 0 阶/4 阶两态验证）。
- 素材：全部来自自备安装包，不含联网/广告/计费 SDK。
